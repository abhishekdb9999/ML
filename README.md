## 📖 List of Experiments

| Lab | Experiment |
|:---:|------------|
| **Lab 1** | Create histograms and box plots for all numerical features in the California Housing dataset to analyze feature distributions and identify outliers. |
| **Lab 2** | Compute the correlation matrix, visualize it using a heatmap, and create pair plots for the California Housing dataset. |
| **Lab 3** | Implement Principal Component Analysis (PCA) to reduce the Iris dataset from 4 features to 2 features. |
| **Lab 4** | Implement the Find-S algorithm using training examples stored in a CSV file to determine the most specific hypothesis. |
| **Lab 5** | Implement the k-Nearest Neighbour (KNN) algorithm to classify randomly generated data points for different values of **k**. |
| **Lab 6** | Implement the Locally Weighted Regression (LWR) algorithm and visualize the fitted regression curve. |
| **Lab 7** | Demonstrate Linear Regression using the Boston Housing dataset and Polynomial Regression using the Auto MPG dataset. |
| **Lab 8** | Implement the Decision Tree algorithm using the Breast Cancer dataset and classify a new sample. |
| **Lab 9** | Implement the Naive Bayes classifier using the Olivetti Faces dataset and evaluate the classifier's accuracy. |
| **Lab 10** | Implement K-Means Clustering using the Wisconsin Breast Cancer dataset and visualize the clustering results. |
